---
name: commit-features
description: Commit full-stack features in a structured way, starting with backend and then frontend.
---

1. When I ask you to commit, check the staged changes and define the scope (FE or BE) of the commit.

2. Follow conventional commits with scope format:
   `feat(BE): <description>` for new features, `fix(FE): <description>` for bug fixes, etc.
